### STEP 3 — BUILD PURE `@graph` JSON-LD INJECTION ENGINE

For every HTML page built in Phase 2, inject a single, validated `<script type="application/ld+json">` inside `<head>` following `output/schema_blueprint.json`:
- **Strict Validation Rules:**
  1. Single `@context: "https://schema.org"` and `@graph: [...]` root.
  2. Cross-page `@id` integrity:
     - `https://[domain]/#academy` (`EducationalOrganization`, `MusicSchool`, `PerformingArtsTheater`, `LocalBusiness`)
     - `https://[domain]/art-cafe/#cafe` (`CafeOrCoffeeShop`, `EventVenue`)

     - Never emit `Offer` with `"price": 0` or empty price.

     - Never emit a fake Fardis street address in `PostalAddress` if Fardis is configured as `SERVICE_AREA_COMMUTER_HUB` (use `areaServed` referencing `فردیس کرج` instead).
